# Calculadora Científica em Flowgorithm

## Descrição
Este projeto é uma calculadora desenvolvida utilizando a ferramenta **Flowgorithm**. Ele apresenta um menu interativo onde o usuário pode escolher realizar diversas operações matemáticas básicas, além de cálculos de áreas geométricas. 

## Funcionalidades
O programa possui um menu em laço de repetição (`while`) que suporta 10 operações diferentes, permitindo múltiplas execuções até que o usuário decida sair:
1. **Soma** (Adição entre dois números)
2. **Subtração** (Subtração entre dois números)
3. **Multiplicação** (Multiplicação entre dois números)
4. **Divisão** (Divisão entre dois números)
5. **Cálculo de Área do Quadrado/Retângulo** (base × altura)
6. **Cálculo de Área do Círculo** (π × r²)
7. **Cálculo de Área do Triângulo** ((base × altura) / 2)
8. **Resto da Divisão** (Módulo)
9. **Potenciação** (Base elevada ao expoente)
10. **Média** (Entre três números solicitados)
11. **Sair** (Encerra o programa com uma mensagem de agradecimento)

## Pré-requisitos
Para abrir e executar este projeto, você precisará do [Flowgorithm](http://www.flowgorithm.org/) instalado no seu sistema Windows ou equivalente.

## Como Executar
1. Salve o código XML/Flowgorithm em um arquivo com a extensão `.fprg`.
2. Abra o arquivo no software **Flowgorithm**.
3. Clique no botão verde de **Executar (Play)** na barra de ferramentas.
4. O console abrirá exibindo o menu. Digite o número correspondente à operação desejada e tecle Enter.
5. Insira os valores (números reais ou inteiros) solicitados pelo console para obter o resultado.
